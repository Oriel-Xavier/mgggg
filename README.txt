WEBSITE PORTOFOLIO ELEGAN

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka file index.html menggunakan browser.
3. Edit nomor payment, nama, tautan WhatsApp, dan isi portofolio pada index.html.

Catatan:
- Fitur penyimpan file menyimpan informasi/nama file di localStorage browser.
- Demi keamanan browser, file asli tidak diunggah dan tidak disimpan ke server.
- Suara bisa dinyalakan atau dimatikan dari tombol speaker di navbar.
